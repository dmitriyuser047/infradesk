# Очистка inventory и удаление Node из Panel

На вкладке «Ноды» история добавления показывает три последних запуска и все выполняющиеся
запуски. Остальные доступны через «Показать всю историю». История не удаляется.

Действующая нода: меню действий → «Удалить из Panel» → подтверждение с именем,
адресом и UUID. Нужны права ManageIntegrations и ExecuteOperations. Запрос отключает
правило управления этой нодой и сохраняет durable операцию NODE_DELETE с requestId.
Участника Fleet сначала нужно явно удалить из Fleet. Активные операции должны завершиться.

Worker повторно проверяет текущие права пользователя, точный target и действующую lease;
затем использует существующий reviewed Remnawave transport. Он проверяет точный UUID,
отправляет максимум один DELETE и подтверждает отсутствие через typed Node lookup.
Timeout, нетипизированный 404 или сохранение Node после DELETE дают UNKNOWN;
автоматического повторного DELETE нет. После потери ответа браузер восстанавливает
ту же отправку с тем же requestId и подтверждением, включая перезагрузку страницы.

Удаление из Panel сохраняет контейнер, TLS и firewall на сервере, связь с ресурсом и историю.
Это отдельное действие от controlled retirement локальной managed установки.
Подтверждённое отсутствие помечает inventory неактивным только при действующей lease
и совпадающем claim token; затем запускается обычная синхронизация.

Запись «Больше не найден»: кнопка корзины → «Убрать из списка». Действие доступно
для нод, хостов и профилей во всех интеграциях. Для ноды в той же транзакции снимаются
правило управления и связь с сервером; членство Fleet требует отдельного удаления.
Операции и recovery history сохраняются. Очистка никогда не вызывает Panel или SSH.
Если синхронизация снова обнаружит тот же external ID, запись вернётся с прежним
внутренним ID и историей. Неполная/неудачная синхронизация не доказывает отсутствие.

V65 добавляет archived_at, ограничения удаления/архивации и защиту от новых ссылок
на архивированные записи. Все запросы ограничены organization/integration scope.
